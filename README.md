# Responsive Internship Board

A beginner-friendly internship listing interface built with semantic HTML, responsive CSS, and vanilla JavaScript. No framework or build step is required.

## Features
- Responsive layout for mobile, tablet, and desktop
- Search by role, company, domain, description, or work mode
- Filter internships by career domain
- Clear filters and helpful empty-results state
- Error message if rendering fails
- Accessible form labels, keyboard focus indicators, skip link, and live result announcements
- Sample internship data stored in `script.js`; no API key or backend required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Search for a role or select a domain to test the filters.

## Deploy with GitHub Pages
1. Create a **public** GitHub repository named `responsive-internship-board`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. Copy the published URL.
